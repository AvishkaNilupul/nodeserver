How this works — shadow mode, ownership, and what is reused from the old engine
🧪 Shadow first. A lane in shadow runs the full decision pipeline and records what it would do — no pool claims, no host writes, no marketplace calls — while the legacy auto-farmer keeps really farming that game. Compare the two below, then promote.
🔒 One owner per game. Only a live lane takes a game off the legacy engine, and it never touches an already-active task — in-flight campaigns finish under the engine that started them, so nothing can be stranded mid-handoff.
🧠 Same brain, new nervous system. Demand tiers, sales boost, probe gates, pricing and the holdings gate all still come from the existing engine's own helpers. This layer replaces scheduling and isolation, not the economics.
