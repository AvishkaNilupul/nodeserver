Backup & Restore

A full backup contains your entire database (orders, accounts, inventory, drops, messages…), uploaded images, and bot/host config. Daily automatic backups run on the server and an encrypted copy of each one is sent to the other servers; you can also back up on demand and download.

What each backup contains
  • The whole database, twice: readable JSON (used by Restore below) and a mongodump archive that also keeps indexes
  • Uploaded images and cached drop images
  • Site settings, host list, and the live bot configs from every bot server, including the no-claim bots
  • The deployed app code as it runs on this server
  • An encrypted secrets bundle: .env, admin logins, database credentials, nginx/TLS, pm2, cron and the side apps in /opt

Restore from a backup
